# NumPy / SciPy

用于数组、数值计算、信号处理、频域分析和 AI 数据预处理。

## 用途与适用场景

先确认输入与目标，再使用 NumPy / SciPy 完成针对性分析。

## 版本检查

```bash
python3 -c "import numpy,scipy; print(numpy.__version__,scipy.__version__)"
```

## 命令、导入与镜像路径

- 常用入口：`python3 -c "import numpy,scipy; print(numpy.__version__,scipy.__version__)"`
- 镜像路径：`Python site-packages`

## 常用工作流

1. 在 Member 工作目录中确认附件、目标地址和授权范围。
2. 按题目类型使用 `python3 -c "import numpy,scipy; print(numpy.__version__,scipy.__version__)"` 进行最小化探测。
3. 保存原始输出，再根据结果逐步增加参数，避免一开始执行破坏性操作。

## 可执行示例

```bash
python3 -c "import numpy as np; print(np.fft.fft([1,0,1,0]))"
```
