# Go

用于构建或审计 Go 题目、网络服务和静态二进制辅助工具。

## 用途与适用场景

先确认输入与目标，再使用 Go 完成针对性分析。

## 版本检查

```bash
go --version
```

## 命令、导入与镜像路径

- 常用入口：`go`
- 镜像路径：`/usr/bin/go`

## 常用工作流

1. 在 Member 工作目录中确认附件、目标地址和授权范围。
2. 按题目类型使用 `go` 进行最小化探测。
3. 保存原始输出，再根据结果逐步增加参数，避免一开始执行破坏性操作。

## 可执行示例

```bash
go version
```

## 输出解释

重点检查退出码、错误输出、命中项、地址/偏移和生成文件；将可复现结论记录到项目事实与 WP。

## 常见错误与限制

版本和参数可能随镜像升级变化，执行前先查看 `--help`。
